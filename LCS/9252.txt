9252 - LCS 2

입력 : 문자열 2개, 가장 긴 문자열 & 문자열 길이 출력

조건 : 문자열 길이 최대 1000, 문자열 모두 대문자

기존 LCS는 단순 길이만을 출력하는 문제임
하지만 이 LCS 2 문제는 해당 sub sequence까지 출력해야함

1. structure 구조
기존에는 dp에 2D map을 사용해서 2개의 for loop을 통해 차례로 접근해 나갔음
이때 기존에는 int형만을 사용하여
만일 x_i = y_j라면 [i-1, j-1] + 1을 하고, 
만일 아니라면, [i-1, j]랑 [i, j-1] 중 더 길이가 긴 것을 가져온다.
structure 구조를 사용해 int, string을 저장한 2D map을 사용한다면 동일하게 가능할 것이다.

==> 시간 초과 발생
이는 매 iteration마다 struct 내부의 string = string + char을 하며 string 전체 데이터 복사하는 과정에서 시간 초과 발생했음

==> structure가 아닌, 매 iteration마다 어떤 방향의 배열의 값을 사용하는지를 저장하는 2D map을 하나 더 둔다.
만일 [i, j] = [i-1, j-1] + 1로 저장한다면 direction은 {1, 1}저장하고,
[i, j] = [i-1, j]로 저장한다면 direction은 {1, 0}저장하고,
[i, j] = [i, j-1]로 저장한다면 direction은 {0, 1}저장한다.

이후 기존 map 끝 지점인 [N, M]에서 direction map에 접근해서 계속해서 index 타고 가며 {1, 1}인 경우만 result string에 저장
이후 result string 순서 반대로 저장되어있으므로 algorithm library reverse 사용
